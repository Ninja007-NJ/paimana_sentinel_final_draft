# What-if simulation

Only progress velocity, expenditure velocity, stagnation duration, required progress per remaining month and schedule pressure can be changed. Bounds are derived from the central 98% of frozen reference observations. Identity, geography, sector, ministry, project age and past facts cannot be edited.

The simulator copies the latest row, changes selected inputs in memory and reruns the frozen model. Stored data is never modified. “This scenario reflects model behavior under modified inputs and does not imply guaranteed causal impact.” Suggested scenarios are limited to three plausible directional changes and are ranked by estimated model-risk difference and change feasibility.
