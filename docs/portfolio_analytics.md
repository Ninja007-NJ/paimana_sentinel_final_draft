# Portfolio analytics

Portfolio analytics use the latest available snapshot for each monitored project. The overall view reports project count, mean and median frozen-model risk, HIGH/CRITICAL counts, rapid-rise counts, average data reliability, active alert count, and aggregate reported original cost, current forecast cost, and expenditure.

Sector, ministry/department, and state comparisons expose their sample size and suppress groups with fewer than 10 projects. Group tables include mean and median risk, HIGH/CRITICAL concentration, rapidly rising projects, reliability, costs, expenditure, and mean one-observation risk movement. Rankings are descriptive monitoring aids, not performance verdicts.

The trend view uses only predictions generated for each historical snapshot from fields available at that snapshot. Missing monetary values are excluded from sums rather than converted into fabricated values.
