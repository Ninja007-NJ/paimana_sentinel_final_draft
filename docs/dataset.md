# Dataset v1.0

The frozen dataset contains 22,972 cleaned project-month records covering 2,804 projects, with no duplicate project-months, approximately 99.88% target-date coverage, and an average data-quality score of about 90.35. The primary three-month training set has 10,368 valid rows across 2,154 projects: 1,933 positive target movements and 8,435 negatives (18.64% prevalence).

Monthly public OCMS / PAIMANA monitoring reports from approximately January 2025 through April 2026 were reconciled into a longitudinal project-month panel. Conservative identity matching, extraction audits, reporting-regime controls, and exclusions protect label semantics. Source reporting changed from legacy OCMS to PAIMANA during 2025; that transition affects scope and field semantics and must not be interpreted as a real project change without supporting evidence. Builders and cached PDFs are outside product-runtime scope and are not modified by this application.
